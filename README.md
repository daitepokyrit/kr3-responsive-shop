# PACE — адаптивный магазин кроссовок

Учебный многостраничный сайт магазина кроссовок для практического занятия №12. Проект показывает адаптивную вёрстку на HTML и CSS без Bootstrap. Базовые стили рассчитаны на мобильный экран; более широкие макеты добавлены в `css/responsive.css` через медиазапросы `min-width`.

## Запуск

Распакуйте проект и откройте `index.html` в браузере. Для загрузки карты Яндекс браузеру понадобится интернет. Проект не использует backend, npm или сборщик.

## Страницы

- `index.html` — главная, hero-блок, категории и популярные модели.
- `catalog.html` — поиск, фильтры по назначению и размеру, сортировка.
- `product.html` — детали модели и адаптивная таблица характеристик.
- `order.html` — форма заявки с выбором модели и размера.
- `about.html` — информация о концепции магазина.
- `contacts.html` — контактный номер, часы работы и карта Яндекс.

## Адаптивность

- На всех страницах настроен `meta viewport`.
- `css/style.css` содержит базовую мобильную раскладку.
- `css/responsive.css` добавляет сетки и размеры для ширин 480, 768, 1024 и 1440 пикселей.
- Каталог перестраивается от одной колонки на телефоне до четырёх на широком экране.
- Hero-блок использует `<picture>` для отдельной композиции на телефоне и широком экране.
- Изображения имеют `width`, `height`, `alt`, `max-width: 100%`; карточки загружаются с `loading="lazy"`.
- Форма на телефоне располагает поля в одну колонку; на широком экране часть полей переходит в две колонки.
- Таблица характеристик находится в `.table-wrapper` с горизонтальной прокруткой для узких экранов.
- Меню доступно с клавиатуры и сворачивается на мобильной ширине.
